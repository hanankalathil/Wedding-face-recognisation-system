Camera Connection Instructions

Sony Camera FTP Setup

  1. Connect camera to the same WiFi network as this PC.
  2. Go to Menu → Network → FTP Transfer settings.
  3. Set Server Address to PC local IP address.
  4. Set Port to 2121.
  5. Enter User: camera, Pass: camera.
  6. Enable "Auto Transfer" in FTP options.

Canon Camera WiFi Setup

  1. Enable Wi-Fi on the camera.
  2. Choose "Transfer images to FTP server".
  3. Select "Configure online" and connect to the WiFi.
  4. Under IP Address settings, select FTP Server address. Enter PC local IP.
  5. Set port to 2121, and login details.

Nikon / Other Cameras

  1. Set up an FTP connection profile in your camera network menu.
  2. Use IP address and port 2121 as the FTP host.
  3. Set transfer mode to Auto to send photos instantly as you shoot them.
